## v0.1.24 (2026-11-21)

## v0.1.22 (2026-11-18)

- **kCFI hashes named by their C function type, from BTF.** A kCFI hash is the low 32 bits of xxHash64 of `_ZTS` + the Itanium-mangled function type (`long (short, int)` -> `_ZTSFlsiE` -> `0x1300e12b`). New `cfiscope/kcfi_types.py` reads BTF (an ELF `.BTF` section, a raw BTF file, or the blob inside a raw kernel `Image`), mangles every `FUNC_PROTO` (functions and function-pointer types such as struct ops members; typedefs resolved, top-level qualifiers of parameters dropped but kept on the return type as Clang does, K&R `()` prototypes mangled without a parameter code, substitutions such as `_ZTSFiP7sk_buffS0_E`) and maps hash -> type and example names. The command line uses the input's own BTF automatically, or `--btf PATH` (`--no-btf` turns it off): `--sites` prints `hash 0x4f4ccb9d (int (struct file *, int))`, `--json` adds `type`, `type_mangled` and `type_examples` per kCFI site, and the summary adds `kCFI hashes named: N of M (x%)`. Without BTF the output is unchanged.
